Run replays

On each task the model submits answers repeatedly, and the checker returns one verdict per submission: accepted, rejected, or rejected on form. This page replays all 768 verdicts from 30 tasks on 5 benchmarks in order. The data comes from the paper's run records; the model is from the DeepSeek Flash family.
